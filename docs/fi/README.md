# Kai Music [[En](docs/README.md)]

Reaaliaikainen musiikin suoratoistosovellus, jonka avulla käyttäjät voivat kuunnella musiikkia yhdessä jaetuissa kuunteluhuoneissa.

## Ominaisuudet

- **Jaetut kuunteluhuoneet** — Kuuntele musiikkia yhdessä reaaliajassa.
- **Synkronoitu toisto** — Pidä toisto synkronoituna kaikkien kuuntelijoiden välillä.
- **Musiikkikirjasto** — Selaa ja hallitse saatavilla olevia kappaleita.
- **Reaaliaikainen suoratoisto** — Suoratoista ääntä WebSocketien ja Media Source Extensions -rajapinnan avulla.
